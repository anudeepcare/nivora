# NIVORA V32 — Decision Intelligence

V32 is designed around one rule: the user should understand the decision in about two seconds, while deeper evidence remains available underneath.

## 2-second Decision Command Center
- Separates **Time horizon** (Now / Swing / Long term) from **My position** (Looking to buy / I own it).
- New-position calls focus on BUY ZONE / START SMALL / WAIT / DON'T CHASE.
- Owner mode can return ADD SELECTIVELY / HOLD / TRIM / REDUCE RISK / REASSESS.
- Shows buy/add zone, confirmation or trim-strength zone, and reassessment level immediately.
- Six interpreted signals: Business, Trend, Entry, Institutions, Options, Valuation.
- Shows the next decision trigger and "What changes the decision?"
- Why / Full thesis / Explore analysis scroll directly to the research section.

## Institutional Intelligence
- New server endpoint uses the connected Finnhub institutional ownership and insider endpoints when available.
- Reported ownership activity is explicitly labeled delayed.
- Insider buys/sells are separated from institutional ownership.
- Daily price/volume accumulation is a separate proxy and never claims a named institution is buying today.
- Institutional evidence is included in Pro data-quality coverage.

## Market / Quant Intelligence
- Accumulation proxy from flow + trend + momentum + structure.
- Fibonacci 38.2 / 50 / 61.8 confluence levels.
- DCA/accumulation zone combines entry/support and swing structure.
- Elliott-style wave candidate with confidence, target and invalidation.
- Pro Technical Lab includes a confluence chart overlaying Fib, trend, NIVORA levels, wave target and wave invalidation.
- Wave analysis is deliberately heuristic and never presented as fact.

## Beginner → Investor → Pro
- Simple: decision, levels, interpreted signals, next trigger.
- Investor: thesis, fundamentals, institutional intelligence, catalysts, news, earnings and options research.
- Pro: Intelligence Grid, Pro cockpit, Technical Lab, confluence/wave/Fib research, Options Lab, audit/data quality.

## Branding / product explanation
- NIVORA favicon, PWA icons and Apple touch icon retained.
- Browser metadata: NIVORA — Market Intelligence.
- About and FAQ explain how the system differs from a screener and how better data providers can improve the evidence layer.
- No guaranteed-return or unproven institutional-grade performance claims.

## Data caveats
Reported institutional ownership is delayed. Accumulation is a market-behavior proxy. Elliott-style waves are heuristic. Fibonacci is supporting evidence. Options quality depends on the connected provider. Predictive alpha remains something the validation system must measure, not a marketing assumption.
