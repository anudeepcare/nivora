# NIVORA V6.1 — Mobile-first

This build adds a true mobile-first responsive layer across landing, authentication, home, analyze, stock decision, watchlist/profile pages.

Highlights:
- iPhone/Android viewport + safe-area support
- compact sticky top bar and thumb-friendly bottom navigation
- no horizontal page scrolling
- mobile decision hierarchy: verdict first, then entry/breakout/risk
- 2x2 decision level grid on phones; 1-column on very small screens
- touch-friendly search, watchlist and auth controls
- responsive chart container
- stacked scenarios/evidence cards
- mobile search results constrained to the viewport
- cleaner auth and landing layouts

Keep `.env.local` on your machine. It is intentionally excluded from the distributable zip.
