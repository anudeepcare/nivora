# AURYN V9.9.9.24 — Always-On Price State
AURYN now has one research-display price state instead of treating execution verification as a prerequisite for a useful masthead. Fresh session-valid observations render as LIVE / PRE-MARKET / AFTER HOURS / OVERNIGHT. When no fresh observation exists, the quote service returns the newest timestamped provider observation (up to 24h) as LAST_AVAILABLE; the client compares it with canonical verified research and displays whichever is newer as LAST AVAILABLE or LAST VERIFIED. Neither state is execution-eligible or labeled Current in the Overview. If no trustworthy observation exists, the state is PRICE UNAVAILABLE.

Normal UX contains only price, session/status, and exact provider observation time plus human-readable age. Provider diagnostics remain internal and are not rendered in the masthead. Quote refresh runs every 30 seconds while visible and immediately on initial load, ticker change, window focus, visibility restoration, and network reconnect. Alpaca Free remains explicitly IEX (`feed=iex`); Twelve/Finnhub remain independent fallbacks. Existing execution Market Truth remains strict.
