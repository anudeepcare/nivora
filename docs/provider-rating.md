# Optional composite Rating evidence

Official contract checked 2026-11-18: https://sentisense.ai/docs/api/sentisense-rating/ . This slice uses only GET /api/v1/rating/{ticker}, on explicit user request in Indicators → Composite rating. It is external descriptive evidence, not Pace, a buy signal, forecast, suitability assessment or an Auryn-generated grade. No engine/model inputs changed. Rating history and rating-based screener filters are outside this slice.

The flat response is projected to closed primitives. Exact returned ticker must match the request; provider canonicalization to another class is withheld rather than relabeled. Score and letter are shown together, separately from pre-adjustment percentile and the actual reported adjustment points. Rated responses below the documented four-dimension or 50% covered-weight floor are rejected, never repaired or graded locally. The documented score bands and floor arithmetic are checked with 0.11-point tolerance for published one-decimal rounding, never used to generate a missing score. Unknown adjustment names are retained with their actual reported points. Raw dimension readings retain their labels/units and are not mixed on a shared scale; only percentiles use meters. Smart-money present=true/raw=null is supported, along with its sub-leg readings. Missing dimensions remain unavailable rather than displaying the methodology's synthetic median as observed data.

Normal rated=false returns Not rated, the reason and available dimension count, no default score/grade. Absent anomaly flags are Not assessable rather than inactive. Provider disclaimer and optional betaNotice are displayed alongside evidence; methodology version and source attribution sit in source details. Run date is the daily run, not an intraday quote timestamp. It can include previous-session inputs and latest available filings. Source retrieval and session reuse are distinguished; an open view can age and manual refresh is provided. Session reuse is one hour with no polling, no claim of automatic daily refresh.

Server-only fixed origin/path, 12-second timeout, redirect refusal and 2 MB streaming cap; no credentials or raw provider errors returned. Market auth, deployment restriction, advanced product feature, six-per-minute user limit and research reservation precede provider calls. Shared endpoint limiter is 20/minute. Provider Rating itself is full on Free keys but consumes provider quota; product gates do not assert provider entitlement. 404 unknown/not covered, 429 quota and malformed/identity responses remain distinct from normal unrated results. No preview wrapper is documented, so unexpected wrapped/preview payloads are withheld.

Synthetic test-first projector, transport, auth/quota and route-to-render checks cover score/rank distinction, unknown risks, smart-money null raw, absent flags, normal unrated, exact identity, date/number validation and bounded body. No live API calls, provider entitlement verification, deployment or visual-browser certification performed.
