Official contract reviewed2026-11-18: https://sentisense.ai/docs/api/analyst-ratings/ , /people/{slug}, /people/{slug}/calls, and per-ticker coverage.

Entry is the existing Coverage dataset. Only supplied analysts[].slug values create profile buttons; null slugs remain unlinked and no name-to-slug guess is made. Existing unnamed firm records remain visible. The closed intelligence DTO explicitly retains name+slug only for these links. No automatic profile call occurs until a person is selected; detail and calls are separate user-selected requests.

Profile shows publication observation windows, most recently published-under firm (not employment), counts and coverage; preview total is preserved. Calls use fixed25rows per page, offsets in multiples25 up to10000, newest-first day dates, publishing firm at the time, original target, split-adjusted target and price-when-posted independently. No target return or accuracy/win-rate scoring. Units are as published; no currency invented. HTTPS source links only. Free first25 is not necessarily preview, so paging uses returned count and total; a preview response disables further paging. At a requested offset above zero, preview rows are withheld rather than mislabeling a repeated free-allowance slice as later history. Unknown slugs/entitlement failures are unavailable, not empty successful histories.
