## Verification

- `npm run verify`: 49 automated domain/Postgres tests, generated route types, TypeScript and production build passed.
- `npm run test:api`: 24 baseline built-handler checks plus 12 repair regressions passed.
- Real read-only providers, called through local built handlers with a fixture identity: BTC/USD, ETH/USD, WYFI, TE, FIGR, CRM, SAP, NOW, ASTS and NU all returned prices. Research facts, filings and history were populated for the four research probes. See `verification/live-provider-fix-check.json` for timestamps and counts.
- These local checks do not establish authentication, rendering, mobile gestures or write operations on the deployed application. No broker orders or paid AI requests were made. No account positions or watchlist entries were changed.

## Items that still need attention

1. NU's connected SEC structured facts stop at December 2024. Missing newer facts are not estimated from today's share price. Use the dated source reports until a verified newer source is connected.
2. Twenty legacy equity records in the account had no cost currency. Use Portfolio → Review currencies only if the displayed costs really are USD; otherwise edit individual positions. Foreign or unknown cash remains excluded from USD totals.
3. One saved crypto record uses `ETHA/USD`. The connected instrument was not silently replaced. If this is an Ethereum ETF holding, review its actual ticker and units in the position editor; if it is Ether, verify the holding before correcting it to `ETH/USD`.
4. The existing provider budget remains in effect. Large portfolios can wait for the next credit window; this repair does not promise unlimited instant quotes. Quote times are source observation times, not fetch times.
5. Actual desktop/light/dark browser review and an installed iPhone PWA test remain required. The managed Sites workflow requires the unavailable control-browser capability and disallows an improvised browser path. No pixel-match or device-test claim is made.
6. Optional paid AI and paper execution remain off unless separately configured and enabled. This repair does not turn on charges or automatic trades.
