- Portfolio periods now use real snapshot windows: 1D, 1W, 1M, 3M, 6M, YTD, 1Y, 2Y, 3Y, 4Y, ALL.

- Added Action Center and Portfolio X-Ray.
- Global mobile readability increased across Analyze, Portfolio and Trading Lab.
- Metric info affordance is a clean standalone i with a large invisible tap target.
- Mobile navigation uses restrained glass treatment.
- Daily snapshots refresh back into Portfolio after successful capture.
