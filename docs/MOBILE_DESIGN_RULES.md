# AURYN design constraints

- Desktop: top navigation, no sidebar.
- Phone/PWA: floating glass bottom navigation, safe-area spacing; no duplicate top navigation.
- Never add decorative colored top borders to Pace or metric cards. Use restrained surface tint instead.
- Center segmented-control labels; align financial values consistently.
- Long tabs must not shrink into overlapping text.
- Metrics help is an accessible icon beside metrics, not a separate full-width row.
- Mobile uses native system typography; avoid decorative font-axis treatment.
- No decorative colored side borders on earnings/context cards either.
