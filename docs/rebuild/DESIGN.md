# Auryn ground-up experience

Fresh composition, not another layer of overrides. Preserve account/session, holdings and provider contracts. No deployment or migration.

The visual language is pearl glass, strong ink typography, measured indigo accents and open editorial spacing. Public entry explains three jobs: understand a company, put its price in context, review your portfolio. It does not fake live numbers. Authenticated entry leads with the current task, one decision, one meaningful chart and visible scenarios. Advanced tools remain available through progressive disclosure.

Desktop navigation sits in a restrained top rail. Mobile navigation is a floating four-destination dock with safe-area clearance. All controls are touch-sized, keyboard-accessible and deliberately styled. No default browser buttons or blue underlined footer soup.

Runtime acceptance: no infinite loading; stale data clearly distinguished from missing/error data; populated, loading, empty and failed states verified separately. Live provider checks are independent of visual previews. No invented scenario values or fabricated market charts. Release remains blocked until authenticated workflows, mobile/tablet/desktop rendered QA, data contracts and performance measurements pass.
