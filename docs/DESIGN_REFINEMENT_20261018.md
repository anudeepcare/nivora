# Research design refinement

Refines the eight October 18 reference screens without changing data-provider routing, valuation assumptions, DCA rules, account storage or trading operations.

- Financial snapshots use semantic definition lists with closely paired labels and values. Desktop has two columns; phone uses one.
- Overview and Financials key metrics have compact white surfaces, coloured top edges and clear numbers. Negative/positive states retain text and signs.
- Available financial trend cards fill the row automatically rather than leaving an empty fourth slot. SVG plots use their full allocated width and non-scaling strokes.
- Valuation cases retain all supplied values, disclosures and assumptions; subtle red/blue/green fills reinforce the bear/base/bull grouping. Consensus percentage colour reflects its sign.
- Monthly DCA history uses shorter month labels, smaller cells and distinct multiplier colours. Only stronger daily-close readings receive the extra marker caption; model limitations remain visible below.
- Earnings and reported insider activity have separate aligned surfaces. No quantities, dates or estimates were invented.
- The PWA root layout, dedicated status surface, viewport updater and keyboard logic are byte-identical to the preceding PWA correction ZIP. The earlier collapsing pseudo-element remains removed.

Validation: Financials component test still requires all four primary metrics and four labelled statement pairs. Full test/typecheck/build results are included. No new subscription, paid provider call, deployment, broker order or database mutation was performed. No physical-iPhone or full browser screenshot acceptance is claimed by these automated checks.
