# Auryn readiness assessment — 2026-11-17

Status terms:

- **Functional offline**: behavior works with browser-local or calculated inputs and does not imply live data.
- **Provider-gated**: screen structure and allowlisted route exist, but live schema acceptance is not complete.
- **Blocked**: requires credentials, visual runtime, distributed infrastructure, or explicit deployment approval.

## Release blockers

1. **Live acceptance (P0 for any live-data claim):** safely inject existing credentials into an authorized non-production runtime, probe at most five canonical symbols, and record status/schema only.
2. **Visual QA (P0 for parity claim):** run desktop and mobile screenshot comparison in a browser that can reach the app. Current static/HTTP tests are not visual evidence.
3. **Production security (P0 for public deployment):** cookie-authenticated writes now require an explicit matching Origin, while bearer clients can omit browser Origin. User/session identity lifecycle, distributed abuse limits, distributed provider quotas, durable account data, and external security review remain blockers.
4. **Universe validation (P0 for coverage claim):** live validation is 0/512. The 512 passing model fixtures are synthetic and are not security coverage.

No production or protected preview deployment is authorized by this report.
