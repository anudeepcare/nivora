# NIVORA V65.12 Portfolio Intelligence + Global Mobile UX Design
Goal: Make NIVORA useful within seconds on iPhone while retaining deep evidence underneath.

Global UX: Analyze, Portfolio and Trading Lab use a shared readable mobile scale; body copy generally 15–16px on narrow screens, larger important values/actions, >=40px interactive touch targets, restrained frosted/glass navigation. All metric info affordances use one small standalone i with no visible circle/border/background; invisible tap target stays large and popovers are viewport-safe.

Portfolio hierarchy: (1) You vs SPY vs QQQ selected-period performance and alpha, (2) plain-English portfolio verdict, (3) Holdings Intelligence for every holding, (4) return/risk/alpha drivers, (5) Action Center, (6) Portfolio X-Ray, (7) full holdings/editing.

Time/truth: 1D,1W,1M,3M,6M,YTD,1Y,2Y,3Y,4Y,ALL must drive period-dependent analytics. Exact snapshots are Actual Portfolio Performance. Earlier current-holdings analysis may be shown only as BACKTEST — NOT ACTUAL PORTFOLIO RETURN. Cost-basis P/L is never substituted for selected-period performance.

Benchmarks: SPY and QQQ first-class; matched benchmark extensible. Holdings semantics: Stocks=Shares, Crypto=Units, Cash=Amount. Cash consolidated by currency/type. Company action and portfolio action remain separate; portfolio sizing never rewrites company truth.

Mobile: First viewport prioritizes value, selected-period performance/availability, market comparison and verdict. Secondary metrics scroll/progressively disclose instead of shrinking. Holdings use mobile cards/rows, not squeezed desktop columns.
