# NIVORA V65.25 Responsive System Design

## Goal
Restore a premium desktop experience while preserving and refining the mobile experience, using one shared visual system with separate desktop and mobile presentation rules.

## Experience principles
- NIVORA should feel like a premium investment product/website, not a spreadsheet or admin dashboard.
- Desktop >=1024px and mobile <=720px are separate QA targets.
- One shared typography, spacing, radius, border and interaction vocabulary.
- Desktop navigation is mathematically centered and never collides with the profile avatar.
- Mobile navigation remains a fixed three-destination bottom dock.
- Information icons remain subtle secondary affordances.
- Analyze emphasizes decision hierarchy and readability.
- Portfolio desktop holdings become refined investment rows with breathing room, not compressed spreadsheet rows.
- Portfolio mobile holdings remain compact editorial cards.
- Trading Lab and Alerts inherit the same typography/card/button rhythm.
- Visual Intelligence must show useful content states and never waste large empty canvas space.

## Safety and data constraints
- No scoring-policy changes.
- No quote-integrity changes.
- No portfolio-math changes.
- No Trading Lab execution/risk changes.
- No new Supabase migration.
