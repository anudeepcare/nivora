## Intent
Make research comprehensive and easy to scan: assessment and Pace first, then operating metrics, price scenarios, technical context, ownership and events. Keep full research tools available in the existing tabs. No illustrative numbers enter real research.

## Visual contract
- White/light neutral continuous canvas, dark readable sans-serif typography, blue actions, green strengths, red risks, amber caution. Honour dark/accent/text/motion preferences.
- Compact consistent header, one tab baseline, restrained radii. No large empty verdict banner, recurring pastel boxes or bordered KPI card grids.
- Overview has four purpose-built areas: operating evidence, price and expectations, price chart with technical readings, and ownership/events. Render real finite observations with labels, dates and help. Unsupported models remain honestly labelled.
- Mobile presents the same content in readable vertical order without squeezed columns. Minimum 44px interaction targets. Preserve the existing installed-PWA viewport/safe-area mechanism.
- Public home, authentication, settings, plans, forms and support adopt the same typography, controls and neutral surfaces. Remove presentation duplication, never remove useful tools or users' data.

## Scope and boundaries
All routes and tabs in docs/SCREEN_INVENTORY.md are in scope for visual review. Existing API integrations, access policy, authentication, subscription, quote refresh and calculations remain intact. Sector-specific evidence and cryptocurrency must not inherit invented company metrics. New market models and data subscriptions are not part of this visual build.
