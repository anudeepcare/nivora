# NIVORA V65.18 Premium UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a cohesive, fast, mobile-first premium UX across NIVORA's primary product surfaces.

**Architecture:** Consolidate responsive visual primitives in the existing shell/CSS and reuse existing data APIs. Preserve engine semantics while changing presentation, request scheduling, navigation geometry and portfolio visualization behavior.

**Tech Stack:** Next.js, React, TypeScript, CSS, existing NIVORA APIs/Supabase

**Spec:** `docs/superpowers/specs/2026-09-04-v65-18-premium-ux-design.md`

## Global Constraints
- Preserve V65.18 scoring semantics.
- Preserve Trading Lab paper-only/risk gates.
- Preserve quote-integrity protections.
- Mobile-first; desktop remains first-class.
- Use `Qty`, never `Units`, for portfolio quantity labels.
- All metric info affordances are visibly circular.
- Content must never be obscured by fixed mobile navigation.
- No new Supabase migration.
