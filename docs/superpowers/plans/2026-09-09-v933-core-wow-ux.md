> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace the clunky V9.3.2 stock dashboard with one compact always-visible decision core and automatic grounded Astra synthesis.

**Architecture:** Keep all deterministic decision logic intact. Pass canonical execution-plan levels into `InstitutionalDecisionBrief`; render a single dark decision core and three concise evidence narratives, then research tabs. Replace the visible Astra panel with a background auto-review bridge that renders only grounded synthesis.

**Tech Stack:** Next.js 15, React 19, TypeScript, existing AURYN V9.3.1 decision domain, OpenAI Responses API.

**Spec:** `docs/superpowers/specs/2026-09-09-v933-core-wow-ux-design.md`
