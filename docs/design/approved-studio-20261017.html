About this preview

A design reference, not a production release. The app and repository have not been changed.

Use the app navigation, search, tabs and forms. Position edits and alerts stay in memory and reset when this file reloads. No credentials or trades are sent.

The CRM research layout is fully represented. Other instruments contain quote or missing-data examples. Chart paths, technical readings, DCA zones and valuation targets are illustrative. Portfolio totals and scenario percentages are calculated from displayed inputs.

The iPhone frame simulates a small viewport. It is not verification of an installed iOS PWA. Browser rendering and physical-device acceptance remain to be checked.
