# Explicit Publications search

Contract: https://sentisense.ai/docs/api/documents/ (checked 2026-11-18).

The existing Publications surface switches between its unchanged ticker source feeds and an explicit public-topic search. Search never incorporates current ticker, holdings, account data or Ask conversation. Before submit, the user sees that the entered query goes to SentiSense. Authenticated POST body contains only query (2–240 characters), kind (stories/links), and days (7/14). No search or details prefetch; one provider request per submit, no fanout or automatic pagination. No raw query in application route URL or reserveAccess record; upstream documented GET necessarily contains query. No query persistence added.

Stories use /api/v1/documents/stories/search, with limit20 and documented days. Source links use /api/v1/documents/search, all supported sources, also limit20/days. Documents endpoint maximum14days is respected. Story endpoint permits30 but UI intentionally bounds both modes to14. Query/entity matching can fall back to keywords: never reinterpret results as verified current-stock evidence. Raw tickers are displayed without guessed listings. Stories preserve provider authorship; source links project source name/URL/time only, never publisher headlines/body. Missing publication/breaking timestamps stay missing; cluster assembly time is separate. Result count is returned count, not a complete coverage claim.

Route uses market-account authentication, news feature, sample restriction, six requests/user/minute and research reservation. Server uses existing shared provider guard, fixed host/path, redirects denied, no-store,12second timeout,2MB stream response cap. Input body2KB cap. Preview states retained, unsupported shapes withheld, errors sanitized. HTTPS links only, credentials prohibited, no external fetches/images/markdown execution. Ordinary React escaping applies. Full story details are deliberately not requested; existing ticker-scoped detail authorization cannot be reused for unscoped search results without a separate reviewed design. Free story-detail allowance therefore not consumed by this feature. API quotas/rate limits remain applicable.

Tests cover query bounds, cross-company story results, copyrighted-field omission, unsafe links, previews, actual shared guard, source/story paths, route authorization/entitlement/quota/body limits, explicit form submission, route→guard→projector→SSR. Synthetic fixtures only; no live endpoint/entitlement/browser confirmation. Redistribution permissions are not conferred by these tests.
