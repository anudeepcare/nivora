# NIVORA V7 — One Glance

V7 changes the product from an indicator dashboard into a decision product.

## First glance
- Buying now / Swing / Long term horizon switch
- One answer: BUY / START, WAIT, DO NOT CHASE, or WATCH
- Exact pullback area, breakout confirmation, hold/watch line, and technical invalidation
- Plain-English Business / Trend / Momentum / Entry / Risk strip
- Price chart with mapped levels
- SEC filings/catalysts and optional live news are visible without opening an evidence drawer
- Raw indicators and detailed fundamentals stay behind “technical evidence”

## Data integrations
- `TWELVE_DATA_API_KEY`: price history, search, stocks and supported crypto pairs
- SEC EDGAR: company fundamentals and material filings (no key)
- `FINNHUB_API_KEY`: optional live company headlines
- Supabase: authentication, watchlists, alerts/profile data

## UX
- White/light premium UI
- Mobile-first responsive layout
- Bottom navigation on phones
- Clean create-account and sign-in screens
- The black circular `N` shown at bottom-left in local screenshots is the Next.js development indicator. It is not NIVORA UI and does not appear in production builds.
