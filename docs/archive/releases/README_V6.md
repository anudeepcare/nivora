# NIVORA V6 — Decision First
This build fixes the missing `/analyze` route and restructures the product around the investor's actual questions.

Primary screen order:
1. BUY ZONE / START SMALL / WAIT / DON'T CHASE.
2. If buying today.
3. If already holding.
4. What changes the call.
5. Best entry, breakout trigger and risk line.
6. Price chart.
7. Technical evidence is hidden until requested.

Existing Supabase auth/watchlist and Twelve Data analysis are retained. No database migration is required.
