# NIVORA V28 — Progressive Intelligence

V28 keeps one engine and progressively discloses complexity.

## View depth
- Simple: decision, plan, concise NIVORA answer, thesis/options access.
- Investor: adds performance, chart, research tabs and supporting evidence.
- Pro: adds full score decomposition, Technical Lab and full Options Lab.

## Answer-first UX
A computed NIVORA Answer panel answers:
- Why not more aggressive?
- What changes the call?
- Biggest risk?
- Do signals disagree?

## Principle
Same underlying engine and decision for every view. The interface changes depth, not truth.
