# Where to find the broader features

- Home: portfolio context, changes observed during the session, upcoming events and recent headlines. Empty watchlist falls back to holdings.
- Research / Overview: separate business, valuation and timing; monthly contribution reading; price chart; visible scenario sensitivities; earnings checkpoints.
- Research / Financials: simple primary numbers, annual/quarterly trend charts, professional financial detail by group/period with formulas, and up to four user-selected comparison columns. CSV downloads preserve periods/currency/basis.
- Research / Technicals: grouped studies, Fibonacci anchors, confirmed/forming DCA, strongest daily-close readings and equal-budget historical comparison with selected cost assumptions. No contribution amount entry.
- Research / Thesis: reported strengths/risks, ownership, insider activity, news, filings and existing opt-in evidence-linked AI. Empty AI setup does not prevent reading company evidence.
- Account menu / Alerts: price, confirmed monthly zone, filing and approaching earnings rules. Run Check alerts manually; background checking requires the operator job configuration in DEPLOYMENT.md.
- Account menu / Discover: bounded saved-universe screening and saved filters; research cache reused.
- Bottom of Research: dataset coverage and observation dates.

These features use the existing server-side subscriptions and caches. Neither an All-in-One plan nor an SDK method proves access to every third-party dataset. Unavailable fields remain unavailable. See BROAD_BUILD_STATUS.md before treating this as release acceptance.
