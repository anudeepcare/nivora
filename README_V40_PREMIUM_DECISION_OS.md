# NIVORA V40 — Premium Decision OS

V40 is a structural UX redesign, not another color pass.

## Product rule
The first screen must answer: **What should I do, at what price, what changes the call, and what breaks the thesis?**

## Decision vocabulary
New position: BUY / START, BUY BREAKOUT / START, ACCUMULATE, WAIT FOR ENTRY, WAIT FOR STABILITY, DON'T CHASE, WAIT / WATCH.
Owned position: ADD SELECTIVELY, HOLD, TRIM SELECTIVELY, TRIM / PROTECT GAINS, EXIT / REASSESS.

## V40 changes
- Premium dark decision contract is the visual anchor.
- New Decision Path makes break → entry → now → confirm → target visible at a glance.
- Thesis no longer opens with a wall of scores. It opens Bull / Base / Bear, then lets users expand the factor math.
- Missing analyst targets say **Not covered** and are excluded instead of looking like a product failure.
- Removed misleading 1x/2x/3x arithmetic from the short-term return block.
- Radar gets premium hierarchy and remains the action-first home screen.
- Mobile turns the price plan and decision path into compact swipeable/stacked decision controls.
- Simple remains decision-first; Investor validates evidence; Pro exposes diagnostics without changing the call.

## Product honesty
NIVORA is decision-support research, not guaranteed outcomes or individualized investment advice. SEC 13F is delayed filing intelligence, not live order flow. Missing data must reduce confidence or be excluded; it must never be fabricated.
