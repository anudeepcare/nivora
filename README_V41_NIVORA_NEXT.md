# NIVORA V41 — NEXT / Decision Intelligence OS

This release is a structural UX reset around one rule: **a beginner should understand the decision in seconds; an experienced investor should be able to inspect the evidence without changing the underlying call.**

## Product architecture
- **Today** — what changed and what deserves attention.
- **Discover** — a curated decision board instead of a giant filter wall.
- **Analyze** — action, price, why, what changes the call, then evidence.
- **Portfolio** — holdings interpreted into attention / hold / review states.
- **Watchlist** remains available from the account menu.

## Analyze UX
- Light-first premium decision card; removed the giant dark hero.
- Plain-English action before scores.
- Separate paths: buy a pullback vs wait for strength. Confirmation is no longer presented as if it must occur before a lower pullback target.
- Replaced jargon such as “between entry and confirmation” with plain language.
- R:R no longer dominates Simple mode.
- Decision confidence is explicitly confidence in the evidence, not probability of profit.
- Four compressed evidence domains: Business, Price Setup, Wall Street, Smart Money.
- “What changes NIVORA’s mind?” is first-class UI.
- Full thesis / technical / institutional / options evidence remains available below for Investor and Pro.

## Portfolio UX
- Portfolio health and attention count.
- Action center for each holding.
- Current price, better-entry research zone, return, and NIVORA action in one card.
- Ticker entry remains simple and mobile friendly.

## Product honesty
NIVORA remains decision-support research. Missing data is excluded or reduces confidence; it is never fabricated. 13F is delayed filing intelligence, not live institutional order flow. Model outputs and mapped levels can be wrong.
