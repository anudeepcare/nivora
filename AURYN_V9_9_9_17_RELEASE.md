# AURYN V9.9.9.17 — Twelve Extended-Hours Pricing Fix
Root cause: fast-quote's Twelve adapter read only `close` and `timestamp`. Twelve Data can return split extended-hours fields where `close/timestamp` represent the regular session while `extended_price/extended_timestamp` contain the current pre/post-market observation. The existing `normalizeTwelveQuote` already understood this contract, but fast-quote bypassed it. V9.9.9.17 routes Twelve through that normalizer before market-price authority selection, preserving the V9.9.9.16 Alpaca quote-mid fallback and execution verification separation.
