Generated by `scripts/audit-active-raw-classes.mjs`, seeded from Product, app layout and all public page entries. Current inventory contains142 reachable component files,1318 raw literal/template class occurrences and101 reachable stylesheet files. JSON records each component, function scope, line, imported-export eligibility, matching active selectors and media/state context. It is intentionally conservative: module reachability is not proof every local helper is rendered; runtime class expressions and imports only used by dead helper branches require manual follow-up. This is source evidence, not a screenshot or browser pass.

`raw-class-reviewed-exceptions.json` records reviewed owners and intentional exceptions rather than falsely calling every unmatched raw name broken. In particular, a semantic root marker can be styled through a composed module class, and a button can be covered by an owned parent selector without a dedicated class rule.
