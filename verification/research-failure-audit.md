# Research/UI historical failure audit

Audit snapshot: current working tree, 2026-10-15. Source log: `auryn/verification/logs/engine-tests-restored-workflows.log`. This report traces every failed `auryn-v4*` through `auryn-v9*` case in that log; two entries are whole files aborted by missing imports. The approved rebuild intentionally removed legacy components. No test is dismissed solely because it is a regex.

## Priority findings

- **B1 HIGH — blocked execution levels leak into display.** `components/StockClient.tsx:546–579` creates `canonicalValidationLevels` from an ungated V934 map or `d.levels` when V5 plan is blocked. At `:902` the Overview receives `v5ChartLevels??canonicalValidationLevels` without a price/trust gate. `components/premium/AurynResearchOverviewV2.tsx:129–133` renders those prices. Technicals `StockClient.tsx:921` also renders `MarketActionMap` without a gate and only checks price, not trust, for execution values. Contradicts explicit blocked-price/trust warning.
- **B2 MEDIUM — watch/reduction levels presented as entries, staged DCA not exposed.** Same files render Entry/Initial entry regardless of `executionPlan.intent`; WATCH, REDUCE, EXIT must not look like accumulation advice. `dcaZones` remain in engine data but have no live rendering.
- **B3 MEDIUM — shared canonical action lost outside Overview.** `StockClient.tsx:897–924` hides V2 outside thesis; `components/stock/StockTabContext.tsx:6` accepts but never destructures/renders action. Only Options retains its own canonical action.
- **B4 MEDIUM — setup/pattern interpretation lost.** V5 scenario is built, but no scenario prop reaches V2. `InstitutionalDecision.setupState` and nextDecisionTrigger/invalidationTrigger are not explicitly explained. Fundamental scenario values are not replacement technical pattern evidence.
- **B5 MEDIUM — two visible plan authorities.** Overview prefers V5 executionPlan chart levels; Technicals additionally exposes V934 action map. Original V934 contract required the canonical action map when available. No calculation changed, but displayed levels can differ.
- **P1 MEDIUM — portfolio capital-priority layer lost.** `app/portfolio/page.tsx` fetches/uses canonical owner calls but does not apply V6 portfolio CIO concentration/correlated-add policy or expose prioritized actions. Concentration figure alone is not equivalent.
- **Q1 role change verified, no bug established.** `app/api/quote/[symbol]/route.ts` delegates to `lib/auryn/fast-quote.ts`, which is explicitly research-only/executionVerified:false. It uses timestamped provider quote normalization/market-price-authority. `app/api/canonical/route.ts` and the canonical market gateway retain official-close and executable-truth ownership. Old import assertions should target the actual authority boundary.

## Focused remediation completed after audit

Parent authorized focused implementation. B1 is corrected at the final rendering boundary: execution display requires verified price, no canonical trust block, and a READY plan. No blocked plan falls back to `d.levels`. Overview, expanded chart, Technicals chart, execution text, weekly level disclosure, and market action map honor the gate. V934 action-map levels now take precedence consistently, resolving B5 without changing any engine algorithm.

B2: WATCH is labeled structural watch, REDUCE/EXIT suppress entry/confirmation/target instructions, ACCUMULATE alone exposes staged DCA. B3: a compact canonical new-money/owner/long-term strip persists on every non-Overview evidence tab. B4: existing canonical setup explanation and exact decision triggers are disclosed; supplemental pattern meaning appears only when the V5 scenario snapshot matches current market snapshot. No alternate pattern targets are introduced. Missing MarketActionMap values no longer render as $0.

Modified: `components/StockClient.tsx`, `components/premium/AurynResearchOverviewV2.tsx`, `components/market/MarketActionMap.tsx`, `components/PriceChart.tsx`. Added `tests/research-execution-presentation.test.mjs`: six React server-render behavior tests passed after first observing the corresponding failures. TypeScript no-emit check passed before the final disclosure; final check result is communicated to parent. No tests were weakened/deleted and no legacy component stubs were restored. Full release tests, production build and browser sweep are owned by parent.

Root follow-up: P1 capital-priority rendering now uses the existing analyzePortfolioRisk/buildPortfolioCioActions policies, excludes unavailable research calls, and withholds sizing when any holding is unpriced. Calibration action-ladder and promotion blockers are restored.
