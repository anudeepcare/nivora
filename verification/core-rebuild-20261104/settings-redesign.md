# Settings design revision

User rejected the teal/blue mixture and stacked rounded panels.

This revision replaces the Settings composition with a slim account/support column and a separate preferences column. On narrow screens the sections stack in reading order. Typography is lighter, section containers are unboxed, controls use compact rectangular segments, and active controls use the selected accent consistently. The redundant breadcrumb/search strip is omitted on Settings; global search remains accessible.

AURYN Blue is the default and reset accent, including the first-paint bootstrap. Explicitly saved user color choices remain supported. The local review preview was switched to AURYN Blue.

This changes Settings and the default accent, not the entire app's visual architecture. No deployment is included.
