# AURYN V9.9.9.23 — Research / Reference Price Regression Fix
Root-cause comparison against the earlier V9.5.3 Market Truth contract found the UI regression: V9.5.3 explicitly preserved canonical verified/reference Market Truth as the display fallback when a fast quote was stale. The newer Overview path removed that fallback during any active session and forced the masthead to `VERIFYING PRICE`, coupling research display too tightly to live execution verification. V23 restores the verified reference price as a clearly labeled `LAST VERIFIED PRICE` during active sessions when no fresh feed is entitled/available. It never marks that reference LIVE, never enables execution, and Overview labels it `Reference`, not `Current`. Provider diagnostics remain available and all V22 multi-provider safeguards remain.
