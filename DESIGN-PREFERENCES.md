# AURYN design requirements

User feedback, 6 November 2026. Apply to future changes.

- Do not use the rejected three-column Pace card layout, colored top borders, repeated divider lines, or tall empty panels.
- Pace is one compact list with small colored badges. Use color for meaning and identifiable icons.
- Admin uses compact, aligned controls and expandable ticket rows; long explanations stay collapsed.
- Mobile selectors must be one control, never a custom popup containing a native select. Avoid automatic keyboard focus for date choices.
- Use readable solid navigation surfaces, touch targets, safe-area spacing and no content overlap.
- Options begin with plain-language summaries, retaining advanced tools behind disclosure. Gamma ranges refer to available expirations, not invented history.
- Do not claim production performance or email delivery from screenshots or local tests.
