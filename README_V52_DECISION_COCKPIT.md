# NIVORA V52 — Decision Cockpit

V52 intentionally removes Radar from navigation until broad-market coverage is trustworthy. `/dashboard` and `/discover` redirect to `/analyze`.

The stock page is redesigned around four questions:
1. Should I own it?
2. Should I buy it now?
3. Why?
4. What would make me sell/reassess?

The first viewport now contains one decision cockpit: thesis + conviction, new-money/owner action, entry/price/breakout/reassess levels, 3M/6M/1Y/2Y/3Y outlook, thesis drivers, risks, thesis breakers, material change, and compact supporting scores.

`Evidence` is renamed visually to `Data completeness` to avoid implying probability of profit. Technical accumulation zones remain timing guidance, not fair value.
