# NIVORA V43 — Smart Decision Calibration

V43 focuses on NIVORA's bread-and-butter: differentiated, horizon-aware decisions rather than a generic WAIT state.

- New-money vocabulary: BUY NOW, START POSITION, BUY ON PULLBACK, WAIT FOR CONFIRMATION, START SMALL, WATCH, DON'T CHASE, WAIT FOR STABILITY, AVOID, BUY BREAKOUT.
- Owner vocabulary: ADD, ADD SELECTIVELY, HOLD, HOLD / DON'T ADD, TRIM, TAKE PROFIT / TRIM, EXIT / REASSESS.
- Horizon-aware action score changes weights for Now, Swing and Long term.
- Price location is one input, not a hard gate that forces every stock into WAIT.
- Missing analyst/institutional evidence stays neutral rather than being invented.
- Visible target is always an upside reference above the current price; pullback and breakout paths are no longer mixed.
- Decision hero is intentionally smaller and calmer. The price plan and "what changes the call" are the primary UX.
- Simple remains decision-first; Investor validates the thesis; Pro audits evidence/model diagnostics.
- Legal baseline retained: research/decision-support, no guaranteed outcome, data/model limitations, no fiduciary/broker relationship by use alone, user verification, liability limits to extent permitted by law, and explicit requirement for separate legal/compliance review before personalized allocation/advisory/execution features.

Important: decision scores are evidence/action scores, not probabilities of profit.
