# NIVORA V13 — Portfolio + Earnings Fix

## Fixed
- Watchlist items can be removed.
- Portfolio positions can be edited or deleted.
- Portfolio shows market value, cost basis, total P/L ($ + %), and estimated daily P/L.
- Earnings tab separates **Latest Reported Results** from **Next Earnings · Estimated**.
- Revenue/EPS estimates are human formatted.
- Latest results can be detected from recent earnings/results news, with SEC financial filing fallback.
- Mobile controls added for watchlist and portfolio management.

## Important
The included `.env.local` is git-ignored. Rotate API keys before public deployment because keys shared in chat should be treated as exposed.

Run:
`npm install`
`npm run dev`
