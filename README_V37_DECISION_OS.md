# NIVORA V37 — Decision OS

V37 focuses NIVORA around a single product promise: **action first, proof underneath**.

## UX changes
- First glance now separates **decision score**, **decision conviction**, and **evidence quality** so a weak 35/100 thesis can no longer read as “high confidence.”
- Adds a plain-English **Best move** sentence, current-location state, upside/downside to the mapped plan, and a 3-step DCA ladder for long-term mode.
- Research navigation is simplified to Decision, Thesis, Business, Smart money, Events, Technical and Options. News + earnings context are consolidated into Events instead of fragmenting the workflow.
- Mobile research tabs are sticky and horizontally scrollable.
- Branding now includes “Decision Intelligence” in the header.

## Product differentiation
- Dashboard is reframed as **NIVORA Radar / Top 20 Decision Board**.
- New product promise strip: Decide → Plan → Explain → Prove.
- Thesis page explicitly states that forward validation is collecting and that NIVORA does **not** claim performance edge before outcomes prove it.

## Important
This release improves the decision workflow and honesty of the UX. It does not prove alpha. The existing validation snapshot pipeline should be used to build a forward outcome dataset before any performance claims or broker automation.
